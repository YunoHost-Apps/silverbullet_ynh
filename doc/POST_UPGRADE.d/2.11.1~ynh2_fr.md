Nouveau sidecar MCP optionnel (désactivé par défaut) : un petit pont Node.js exposant vos notes aux LLM via le Model Context Protocol sur `/mcp` (sans Chromium).

Pour l'activer, cochez « Sidecar MCP » pendant l'installation ou plus tard dans le panneau de configuration (télécharge et compile le pont, quelques minutes), puis créez un token API SilverBullet dans `/.dashboard` → votre utilisateur → API tokens et collez-le comme « Token API SilverBullet » dans le panneau de configuration. Pointez votre client MCP vers `/mcp` avec `Authorization: Bearer <token client MCP>` (affiché dans le panneau, modifiable là-bas).

Contrôlez qui peut joindre `/mcp` avec la permission dédiée `mcp` (fermée par défaut) : les scripts externes ont toujours besoin du token client dans tous les cas.
