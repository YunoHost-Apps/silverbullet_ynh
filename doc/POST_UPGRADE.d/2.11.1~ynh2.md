New optional MCP sidecar (disabled by default): a small Node.js bridge exposing your notes to LLMs via the Model Context Protocol at `/mcp` (no Chromium needed).

To enable it, turn on "MCP sidecar" during installation or later in the app config panel (downloads and builds the bridge, a few minutes), then create a SilverBullet API token in `/.dashboard` → your user → API tokens and paste it as "SilverBullet API token" in the config panel. Point your MCP client at `/mcp` with `Authorization: Bearer <MCP client token>` (shown in the config panel, rotatable there).

Control who can reach `/mcp` with the dedicated `mcp` permission (closed by default): external scripts always need the client token regardless.
